## 👋 About

Cloud and platform engineering leader who builds infrastructure functions from the ground up. At a PE-backed fintech SaaS business, I took ownership of the cloud and infrastructure for 40 engineers across DevOps, Sysadmin and Cloud Infrastructure, running Azure and AWS in a regulated, multi-cloud setup under SOC 2 and SWIFT compliance.

I stay hands-on. Terraform, PowerShell, SQL Server, and observability tooling are still part of my daily toolkit alongside leadership work, so I can set technical direction and prove it in the codebase.
